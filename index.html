ClickFix 疑似体験 ― 「あなた自身の手で」実行させる手口

サポート詐欺やマルウェア配布で使われている「ClickFix」を疑似体験します。この公開版は、実際のコピー処理も実在のコマンドも一切使わない完全なシミュレーションです。画面上の「命令」はすべて表示だけの札（《PCへの悪意ある指示コマンド》）で、何も運ばず、何も実行されません。

種明かし

何が起きていたか

「私はロボットではありません」を押した瞬間に…

あなたはチェックを入れただけのつもりでした。しかしその瞬間、画面右下の「クリップボード（疑似）」が（空）から 《PCへの悪意ある指示コマンド》 に変わっていました。気づきましたか？

本物の攻撃では、これがあなたのPCの本当のクリップボードに対して行われます。コピー＆ペーストの「コピー」が、知らないうちに済まされているのです。

この後の3手順の正体

1. Windows + R
パソコンに直接命令を打ち込む窓「ファイル名を指定して実行」を開く操作。知らない人には「認証の手順」に見える。

2. Ctrl + V
さっき勝手にコピーされた命令が貼り付けられる。

3. Enter
命令が実行される。Windowsに元から入っている正規の道具を本人が動かす形になるため、ウイルス対策ソフトが見逃しやすい。

実際の攻撃では、ここで情報窃取ウイルスや遠隔操作ツールが動き出します。

見破るためのポイント

  • 「人間であることの確認」で キーボード操作（Win+R など）を求められた → 正規のCAPTCHAは絶対に求めません。
  • Webページが 何かの貼り付けと実行 を指示してきた。
  • 「修正」「認証」「更新」を名目に 急がされ、手順どおりの操作だけを促してくる。

もし手順を実行してしまったら

すぐにネット接続を切り、そのPCの使用をやめて情報担当（ICT支援員・教育委員会）へ。別の端末から、そのPCで使っていたパスワードを変更してください。「何も起きていないから大丈夫」と自己判断しないこと。

本教材は教育目的の疑似体験ページです。実際のクリップボード操作、実在のコマンド、外部通信を一切含みません。 参考：IPA 情報セキュリティ安心相談窓口「偽セキュリティ警告（サポート詐欺）対策特集ページ」、トレンドマイクロ Security GO「ClickFix（クリックフィックス）とは？」
